# 为她而唱（music_synth）

N.E.K.O 的本地 AI 翻唱与原创歌曲插件。

采集正在播放的音乐 → 自动切歌 → 人声/伴奏分离 → DDSP-SVC 6.3 音色转换 → 混回伴奏，
一条链路出成品；也能用 ACE-Step 从文字直接生成整首歌，再用训练好的音色重唱一遍。

## 能做什么

- **只听选中的应用**：逐进程声道采集，通知、视频、AI 自己的声音都不会混进来
- **自动切歌**：按静音能量谷和媒体标题变化切分，短片段自动合并
- **音色训练**：投素材 → 分离/降噪/切片/提特征 → 训练 DDSP-SVC 音色，每 2000 步出试听
- **双引擎变声**：DDSP-SVC 6.3（RectifiedFlow）；按显存自动选档位、自动降级
- **原创歌曲**：ACE-Step v1.5-turbo 本地 text2music，支持歌词、风格、BPM、时长、纯音乐
- **一键成曲**：生成后自动分离、变声、混音，直接出成品
- **声音包导入导出**：模型 + 配置打包成 zip，换机或分享都方便
- **全本地**：不联网、不需要账号、音频不上传

## 环境

Windows 10/11 + NVIDIA 显卡（建议 8GB 显存以上）。
DDSP-SVC 与 ACE-Step 通过独立 Python 环境运行，模型权重按需下载到计算根目录。
